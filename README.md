# Personal Portfolio Website

A personal portfolio website built to showcase my **education, technical skills, projects, and professional interests** in Networking, IT Security, Cloud Computing, and Software Development.

The website is built using **Node.js, Express, EJS, HTML, CSS, and JavaScript** and is deployed using **Render**.

This website serves as my personal online portfolio and provides an overview of my background as an **Information Technology student specializing in Networking & IT Security at Ontario Tech University**.

The website was designed to showcase my:

* Education
* Technical skills
* Networking experience
* Cybersecurity interests
* Cloud projects
* Software development projects
* Academic and personal projects
* Professional experience

The site also provides direct links to my **GitHub** and **LinkedIn** profiles.
